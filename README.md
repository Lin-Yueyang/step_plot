# 台阶图 · Step Plot

反应自由能台阶图编辑器，支持多体系、反应分支、可选过渡态及文字样式调整。

当前稳定版：[v0.13](./stepplot-v0.13.html)。

[在线使用](https://lin-yueyang.github.io/step_plot/) · [更新记录](./更新.md)

在线地址在仓库启用 GitHub Pages 后生效。也可下载带版本号的 HTML，用 Chrome 或 Edge 打开，离线使用。

输入 E、Gcorr 与小分子参考项即可绘图；也可直接输入相对能。数据在浏览器本地计算，工程通过“保存工程”导出 JSON，下次用“打开”继续编辑。

保存图形支持 SVG、PNG、CSV，使用浏览器的保存位置选择功能。

旧版 HTML 保留原文件名；首页只跳转到当前稳定版。
